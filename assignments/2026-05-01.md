## Questions

1. PATCH vs PUT in your API: which did you implement and why?
2. How do you avoid overwriting fields the client omitted in PATCH?

---

## Answers

1. PATCH means only update some fields of the record and PUT means replace the whole record.

For implementation, PATCH usually has less payload size as it does not contain the whole DTO but PUT contains the whole DTO to overwrite the existing record.

2. Don't overwrite omitted PATCH fields and only merge properties that client sends.

```js
const payload = { name: "Alfred" };

const existingRecord = { id: 1, name: "Blfred", sex: "male" };

const newRecord = {
  ...existingRecord,
  ...payload,
};
```
