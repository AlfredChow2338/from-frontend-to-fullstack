## Answers

1. `@IsNotEmpty()` on DTO fields (e.g. `title`, `description` in `CreateTaskDto`).

2. `ValidationPipe` is registered globally so request bodies are checked against `class-validator` rules before the controller handler runs.

### Reviewer comments

- **Q1:** Good that you named `@IsNotEmpty()` and tied it to DTO fields. **Add:** failed validation returns **400 Bad Request** with a JSON body listing which properties failed (Nest’s default `ValidationPipe` response). **Syntax:** custom text is `@IsNotEmpty({ message: 'This field is required.' })`, not a string as the first argument. See [class-validator — IsNotEmpty](https://github.com/typestack/class-validator#validation-decorators).
