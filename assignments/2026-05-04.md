## Questions

1. What does `@ApiTags` / `@ApiOperation` buy you in Swagger UI?
2. How do you document auth (Bearer) in Swagger for protected routes?

---

## Answers

1. @ApiTags('group') groups endpoints under the section.

@ApiOperation({ summary, description }) adds title and description on each end point.

2. @ApiBearerAuth('access-token') @UseGuards(AuthGuard('jwt'))

In Swagger UI, use Authorize, paste Bearer <your-jwt> so that Try it out does not returns 401 and looks like a bug.

### Reviewer comments

- **Q1:** Correct: `@ApiTags` groups routes by feature in Swagger UI; `@ApiOperation` adds a human-readable summary/description per endpoint. **Polish:** mention the payoff — discoverability for frontend/reviewers and a living API reference generated from Nest decorators (not a separate doc file).
- **Q2:** Good route-level pieces: `@ApiBearerAuth('access-token')` + JWT guard, and using **Authorize** in Swagger UI before **Try it out**. **Add one step:** register the scheme in `main.ts` with `DocumentBuilder().addBearerAuth(..., 'access-token')` — without that, the Authorize button and lock icons won't appear.
